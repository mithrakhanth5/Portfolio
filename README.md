## 🛡️ Key Features & Domain-Themed 3D Animations

### 1. **High-Level 3D WebGL Threat Matrix (Three.js)**
- **Holographic Cyber Globe**: Dynamic point-cloud Earth with over 2,200 geo-distributed telemetry nodes, rotating inner cryptographic icosahedron core, and pulsing central energy nucleus.
- **Global Threat Vector Arcs**: 3D quadratic Bezier curves simulating real-time cyber attacks (DDoS, SQLi attempt, Recon, C2 traffic) with animated traveling pulse packets.
- **Concentric Defensive Shields**: Segmented HUD defense rings rotating on multiple axes that respond to mouse tilt and scroll choreography.
- **Tactical 360° Volumetric Radar**: Sweeping radar beam with phosphor trail effect continuously monitoring the defensive perimeter.
- **Undulating Cyber Grid Floor**: Infinite synthetic horizon grid plane animated with real-time wave distortion math.
- **Interactive EMP Shockwave Pulse**: Clicking anywhere or selecting vulnerability vectors triggers an expanding electromagnetic pulse ring with synthesized audio.
- **Scroll-Synchronized Camera Choreography**: Smooth cinematic camera transitions and orbital shifts tied to each portfolio section (Hero, Threat Posture, Arsenal, Vulnerability Lab, Ops Timeline, Vault, Certifications, and Comms).

### 2. **Procedural Web Audio API Cyber Synthesizer**
- Zero external audio files required! Procedural audio engine generates:
  - Holographic UI hover chirps
  - Keystroke clicks
  - Radar scan pulses
  - Threat alarm sirens
  - Low-frequency EMP shockwave drops
- Toggleable audio system in the tactical top HUD.

### 3. **Dynamic Multi-DEFCON Threat Matrix Modes**
- Switch between **DEFCON 5 (Secure - Cyber Cyan/Emerald)**, **DEFCON 3 (Elevated Warning - Tactical Amber)**, and **DEFCON 1 (Critical Breach - Crimson Red)**.
- Switching DEFCON dynamically transitions all 3D lighting, fog, materials, particle colors, and CSS styling in real-time.

### 4. **Interactive OWASP & CVSS 3.1 Vulnerability Lab**
- An interactive exploit simulation environment where recruiters and technical leads can explore:
  - **SQL Injection (SQLi)** (CVSS 9.8 Critical)
  - **Stored Cross-Site Scripting (XSS)** (CVSS 8.2 High)
  - **Insecure Direct Object Reference (IDOR)** (CVSS 8.6 High)
  - **Server-Side Request Forgery (SSRF)** (CVSS 9.1 Critical)
  - **Broken Authentication & Brute Force** (CVSS 8.8 High)
- Displays CVSS v3.1 vector strings, simulated exploit payloads, and Mithra's production-hardened remediation code diffs.

### 5. **Interactive Hacker Command Console (CLI)**
- Press **\`** (Backquote) or click the **CLI [~]** HUD button to launch an authentic interactive terminal.
- Supported commands:
  - `help` / `?` — List all available commands
  - `whoami` — Candidate profile and philosophy
  - `skills` — Technical toolchain and penetration testing stack
  - `projects` / `project <1-6>` — Project details and security impact
  - `certs` — Industry cybersecurity certifications
  - `experience` — Professional track record
  - `scan <target>` — Real-time interactive SYN port scan & reconnaissance simulator
  - `qualys` — Automated Qualys VMDR vulnerability scan simulation
  - `matrix` — Full-screen falling digital rain effect
  - `defcon <1|3|5>` — Switch global alert mode from CLI
  - `contact` — Direct transmission coordinates
  - `clear` — Clear terminal buffer

### 6. **3D Tilt Cards & Holographic Sheen**
- Perspective 3D hover tilt on project vault cards with interactive holographic glare.
- Modals for in-depth architectural and vulnerability case study breakdowns.

### 7. **Print-Ready Resume Mode**
- Built-in `@media print` CSS enables one-click clean PDF export (via `Ctrl + P`) formatted as an executive cybersecurity resume.

## 🚀 How to Run Locally

You can open the portfolio in two simple ways:

### Option 1: Direct File Open
Simply double-click `index.html` to open it directly in any modern web browser (Google Chrome, Microsoft Edge, Brave, Firefox, Safari).

### Option 2: Local HTTP Server (Recommended)
Using Python:
```bash
python -m http.server 8000
```
Then visit `http://localhost:8000` in your browser.

Using Node.js:
```bash
npx serve .
```
